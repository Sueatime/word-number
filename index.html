Number Code

Each number is a letter of the alphabet. Decode the numbers in order and type the word they spell.

How to play

The alphabet is numbered A=1, B=2 ... Z=26.

Turn each number into its letter, keeping the same order, and type the word.

Some numbers above the alphabet are hidden each round. Count from the ones you can see to find the rest.

Green letters are in the right place. You can guess as many times as you like.
